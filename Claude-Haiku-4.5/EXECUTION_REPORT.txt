API SPECIFICATIONS IMPLEMENTED

v1 API (Legacy)
  Endpoint: POST /api/v1/charge
  Request:  {orderId, amount, paymentMethod}
  Response: {success: boolean}
  Stateless, synchronous, minimal fields

v2 API (Enhanced)
  Endpoint: POST /api/v2/payments/authorize
  Request:  {orderId, amount, currency, countryCode, paymentMethod, 3DS_token}
  Response: {transactionId, fraudScore, requiresAuth, status, [authUrl, declineReason]}
  
  Webhook: POST /webhook/payments
  Payload: {transactionId, status, fraudScore, event, timestamp}

  Features:
  ├── Rich response data (transactionId, fraudScore)
  ├── Async webhook support (pending_auth, pending_confirmation)
  ├── 3DS/Strong authentication support
  ├── Fraud scoring and decline reasons
  └── Proper HTTP status codes (200 sync, 202 async)
